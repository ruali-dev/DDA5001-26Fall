# PC40 实验

在学校 PC40 上克隆项目并进入实验目录：

```bash
git clone https://github.com/ruali-dev/DDA5001-26Fall.git ~/dda5001-pc40
cd ~/dda5001-pc40
bash p1/run_pc40.sh
```

启动器自动选用学校已安装的 Python 环境，依次进行课程检查、CPU 小训练和 GPU 环境检查，通过后才开始六次正式训练。无需 sudo 或重新安装环境。只检查环境而不开始正式训练：

```bash
bash p1/run_pc40.sh --check-only
```

六次训练会串行运行。使用 `bash p1/run_pc40.sh --only half` 或 `--only default` 可只跑对应的三组；`--eager` 会对所有训练关闭 `torch.compile`。每次执行写入新的 `p1/runs/pc40-时间戳` 目录，不会覆盖旧结果。完整运行结束后会生成曲线、首个实验的文本样例和 `results.zip`。没有预先填写或承诺实验指标。

第二组学习率暂选默认值的一半（AdamW 0.00015、Muon 0.005、SGDM 0.05），用于对照；可以先查看默认组曲线，再按手册调整对应的 `p1/config/pc40-*-half.py`。正式实验保持课程模型、数据、92,160,000 个训练 token、调度器和评估方式不变。预计总耗时约三小时，以实机情况为准。Ctrl-C 会停止当前任务，不会继续启动后面的任务。

PC40 重启会清空 home 目录。离开前把 `results.zip` 和各实验目录中的检查点（`best.pt`、`last.pt`）分别备份到你自己的私有存储并核验；ZIP 不包含检查点或原始数据，实验结果也不会自动上传 GitHub。预留足够磁盘空间：六组完整检查点可能占用数十 GB。

## 上传完整结果到 HF 私有仓库

在 PC40 浏览器登录 `ruali-dev`，从 https://huggingface.co/settings/tokens 新建 Write token。在仓库根目录执行：

```bash
git pull --ff-only
bash p1/backup_hf.sh --compact
```

按提示在隐藏输入框粘贴 token；它不会被写入文件或 Git 凭据。备份工具在用户目录创建独立小环境，不修改课程环境。选择最新的六组完整实验，先上传并核验 `results.zip`，再上传六份最终模型和全部轻量实验记录到私有模型仓库 `ruali-dev/DDA5001-p1-checkpoints` 的会话 `compact` 子目录，最后检查远端大小及文件校验值。

`--compact` 从每组 `last.pt` 提取原始模型权重和配置、tokenizer 等元数据，保持 tensor 的 dtype 和数值不变；跳过 `best.pt`、优化器和 RNG 状态，不包含训练数据。它适用于生成文本、模型复核和留档，不能直接恢复原优化器续训。PC40 原始完整检查点保持不动。如需全量断点续训备份，去掉 `--compact` 即可。

看到 `Backup verified` 后，仍要在 TX3 下载 ZIP 并确认能打开，再离开。中断后重跑同一命令可利用已上传内容继续；本地结果不会被删除。
